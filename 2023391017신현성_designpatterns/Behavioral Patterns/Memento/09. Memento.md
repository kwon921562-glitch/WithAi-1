# Memento Pattern

> **카테고리:** Behavioral Patterns (행동 패턴)  
> **학습 순서:** 9/22

---

### 1. 한 줄 요약

**객체의 현재 상태를 저장해 두었다가 나중에 이전 상태로 복원하는 패턴이다.**

### 2. 사용하는 이유

되돌리기, 체크포인트, 임시 저장처럼 이전 상태가 필요하지만 객체 내부 데이터를 외부에 그대로 노출하고 싶지 않을 때 사용한다.

### 3. 핵심 구조

- **Originator**: 상태를 저장하고 복원할 실제 객체
- **Memento**: 특정 시점의 상태를 담는 객체
- **Caretaker**: Memento를 보관하는 객체

### 4. 동작 과정

1. Originator가 현재 상태를 Memento로 만든다.
2. Caretaker가 Memento를 보관한다.
3. Originator의 상태가 바뀐다.
4. 필요할 때 저장해 둔 Memento를 이용해 이전 상태로 복원한다.

### 5. 게임 개발 예시

플레이어가 체크포인트에 도달할 때 위치와 HP를 저장하고, 죽었을 때 그 상태로 복구할 수 있다.

### 6. 간단한 Lua 예제

```lua
local Player = { x = 10, hp = 100 }

function Player:save()
    -- 현재 상태를 복사해서 반환
    return { x = self.x, hp = self.hp }
end

function Player:restore(memento)
    self.x = memento.x
    self.hp = memento.hp
end

local checkpoint = Player:save()

Player.x = 50
Player.hp = 20

Player:restore(checkpoint)
print(Player.x, Player.hp) -- 10, 100
```

### 7. 장점

- Undo, Save, Checkpoint 구현에 적합하다.
- 객체의 내부 상태를 직접 외부에서 조작하지 않아도 된다.
- 과거 상태를 여러 개 저장할 수 있다.

### 8. 단점

- 상태가 크거나 저장 횟수가 많으면 메모리를 많이 사용할 수 있다.
- Memento 관리가 복잡해질 수 있다.

### 9. 핵심 키워드

`상태 저장`, `복원`, `Undo`, `Checkpoint`, `Snapshot`

### 10. 헷갈리기 쉬운 패턴

Prototype도 객체 상태를 복사할 수 있지만 목적이 다르다.

- **Memento**: 과거 상태로 **되돌리기 위해 저장**.
- **Prototype**: 비슷한 새 객체를 **빠르게 생성하기 위해 복제**.
