# 세션 NNN

이 파일을 `NNN_YYYY-MM-DD_session.md`로 복사한 후 작업한 날의 기록을 채운다. 시작 해시는 수정 전에, 끝 해시는 작업을 커밋한 후 기록한다.

- 날짜와 시각 (KST) —
- 오늘 목표 한 문장 —
- 시작 커밋 / 끝 커밋 —
- 변경 파일과 관련 요건 —
- 검증 명령 / 실제 결과 —

## 프롬프트 기록 #N

세션에서 실제 사용한 프롬프트마다 이 블록을 복사한다.

- 시각 / 당시 커밋 —
- AI 도구, 스킬 또는 에이전트 —
- 목적과 범위 —
- 첨부 파일 및 역할 (명세, 테스트, 수정 허용 파일 등) —
- 프롬프트 원문
  >
- AI 결과 요약 —
- 내 판정 (채택 / 수정 후 채택 / 거절)과 이유 —
- 수정한 프롬프트 원문 또는 다음 프롬프트 번호 —
- 확인한 테스트 또는 변경 근거 —

## AI 오류를 발견한 경우

- 과목 / 관련 프롬프트 번호 / 커밋 —
- 증상과 오류 원문 (경계 위반이면 `layer_check` 출력 원문) —
- 원인 위치 (`파일:줄`)와 발견 방법 —
- 거절 이유 또는 고친 내용 / 다시 검증한 결과 —
