## 설명 문항

각 답은 3~6줄로 쓰고 내 코드의 줄 번호를 붙인다.

1. 일시정지는 왜 `switch` 대신 `push`를 쓰는가? 새 씬은 어느 쪽이고 그 이유는 무엇인가?
2. 씬 상태와 적 AI 상태가 섞이지 않게 코드에서 어떻게 나눴는가?
3. 새 적 1종 추가 시 바뀐 파일을 근거로, Factory와 MVC가 없다면 어디가 더 바뀌었을지 설명한다.

## 번짐 실측 R7

R1~R6 완료 커밋에서 `git tag before-r7`을 실행한다. 새 적과 테스트를 추가하고 커밋한 뒤, 이 프로젝트 폴더에서 아래 명령을 실행한다.

```bash
for d in models views controllers scenes; do
  printf "%-12s %s\n" "$d" "$(git diff -U0 before-r7 HEAD -- project/src/$d | grep -c '^@@')"
done
git diff --stat before-r7 HEAD -- project/
```

| 계층 | 변경 덩어리 수 | 변경 파일과 이유 |
|---|---:|---|
| Model | | |
| View | | |
| Controller | | |
| Scene | | |

변경이 모인 계층과 예상 밖에 수정된 곳을 근거와 함께 3~5줄로 해석한다.
